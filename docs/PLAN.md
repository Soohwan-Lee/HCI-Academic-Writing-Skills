# Development plan

Started 2026-10-30. Working language: English skills, Korean project guide.

## Objective
Build portable, evidence-linked HCI writing skills for CHI, CSCW, UIST, DIS,
and IUI. Route by knowledge contribution, not venue prestige or method alone.
The first release is an exploratory, purposive corpus, not a population survey.

## Stages and review gates
1. Protocol: define contribution taxonomy, sampling, coding, evidence levels,
   private-source boundaries. Review distinctions and feasibility; commit/push.
2. Corpus: obtain full texts across all five venues; verify identity and awards
   separately; select both decorated exemplars and methodological contrasts.
   Review coverage, provenance and missingness; commit/push metadata only.
3. Analysis: record section sequences, rhetorical moves, evidence/claim links,
   related-work positioning, counterexamples and reproducible text measurements.
   Review extraction against originals; commit/push original analytical notes.
4. Skills: common argument/section/style guidance plus contribution-specific
   routes, hybrid routing and adaptable word budgets. Review every empirical
   assertion against evidence; commit/push.
5. Packaging: verify official installation mechanisms for Codex, Claude Code,
   and Antigravity; validate skills and behavioral cases. Review limits of
   compatibility claims; commit/push.
6. Release: create visual identity, professional bilingual-facing README,
   usage examples and evidence navigation. Review links, repository contents,
   claims and remote state; commit/push.

Each gate is a recorded self-review, not an automatic request for user approval.
Claude Code may critique plans and skills using the existing subscription only.
Never upload Zotero PDFs, library databases, private notes or full-text caches.

## Completion criteria
- All five requested venues represented in full-text analytical notes.
- Primary/secondary contribution, method and venue are separate fields.
- Every corpus-derived pattern has named evidence and counterexample/limit.
- Length measurements declare denominator, extraction and boundary limitations.
- Planning budgets are explicitly editorial heuristics, never claimed norms.
- Common and type-specific skills install without machine-specific paths.
- No fabricated references, awards, findings, numeric norms or compatibility tests.

## Later expansion (not a claim about this release)
A larger stratified corpus, multiple independent coders and held-out author
usage are needed before presenting observed writing patterns as robust norms.

## Scope refinement after initial analysis (2026-10-30)
User requested deeper paragraph/sentence analysis and explicitly prioritized
thoroughness over speed. The target is a researcher's AI-assisted writing workflow
inside an existing ACM LaTeX project intended for Overleaf, not only a prose guide.
The first ten papers are a completed pilot, not the final coverage claim.

### Additional milestones before release
- Expand missing coverage: toolkit evaluation, foundational RtD, dataset/resource,
  non-AI situated design, sociotechnical qualitative inquiry and another IUI paper.
  Keep new selection decisions and negative cases explicit.
- Consult Claude separately on researcher workflows, then on a concrete skill,
  then run realistic behavioral cases. Record suggestions accepted/rejected.
- Design fast paths: evidence-to-outline; result-to-claim; section drafting;
  related-work synthesis; paragraph repair; compression; reviewer-driven revision.
  Each path should minimize context collection without silently inventing evidence.
- Build a self-contained skill with selective modules. Include study stage,
  evidence/claim ledger, route-specific section logic and sentence-level examples.
- Add a read-only LaTeX audit helper and test with multi-file ACM fixtures; preserve
  macros, bibliography keys, figures, labels, class options and existing edits.
- Run actual compile checks and model behavior checks on isolated fixtures. Separate
  semantic review from compile success, and documented format support from live
  host discovery. No automatic Overleaf upload or submission is implied.
- Create final README/logo only after the research/workflow modules pass review.

## Binding expansion (latest user direction)
The release target is now **at least 60 analyzed full papers**, broadly sampled
across HCI rather than centered on current human–AI interests. Follow
[SAMPLING-PLAN.md](SAMPLING-PLAN.md). The original ten remain the pilot. Track
coverage and unfinished work explicitly; do not present pilot skills as the final
requested product. Keep progress updates short; spend effort on analysis and review.

\section{Related Work}\label{sec:rw}
% Existing author-owned claims and citation attachments; source full texts are absent.
Prefab reconstructs interface elements from pixels to support interface modification without access to application source code~\cite{dixon2010prefab}. Rico provides a corpus of mobile interfaces that supports data-driven design applications~\cite{deka2017rico}. These studies address different prerequisites for working with existing interfaces. In our setting, analysts already have screenshots, but they need to explain how neighboring screens support a task. The missing support in our workflow is therefore a way to inspect relationships across screens, rather than a way to obtain the application source or collect more isolated screenshots. This distinction motivates our focus on connecting the available screens during analysis.

# Hierarchical structure maps

These maps deepen selected corpus analyses. Each distinguishes actual source
organization from proposed writing guidance. A completed paper note is not
necessarily a completed map, and a map can cover selected subsections rather than
every paragraph in a manuscript. See the [active plan](../../docs/STRUCTURE-ANALYSIS-PLAN.md).

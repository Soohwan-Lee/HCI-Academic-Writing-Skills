# HCI Academic Writing Skills

ACM LaTeX 프로젝트에서 논문을 작성하는 연구자를 위한 근거 기반 라이팅 스킬입니다.
Codex, Claude Code, Antigravity에서 사용할 수 있도록 개발하고 있습니다.

[English](README.md) · [개발 계획](docs/PLAN.md) ·
[분석 논문 목록](research/CORPUS.md) · [검토 기록](docs/REVIEW-LOG.md)

**개발 중입니다.** 현재 전문 분석과 검토를 마쳐 통합한 논문은 87편입니다.
CHI, CSCW, UIST, DIS, IUI의 **최소 100편**을 분석하는 것이 릴리스 기준입니다.
검토 대기 분석과 확보 예정 논문은 완료 수에 포함하지 않습니다.
설치 방식과 실제 논문 작성 지원 기능은 검증 중입니다.

## 만들고 있는 것

- 논증, 초록, 서론, 관련 연구, 문단 전개, 문장 간 연결과 주장 범위를 다루는 공통 지침
- 정량·정성 연구, 시스템, 디자인 지식, 개념·이론, 방법, 데이터·리소스,
  문헌 리뷰의 기여 유형에 맞는 작성 경로
- 기존 ACM 프로젝트의 여러 tex 파일을 수정하며 개요 작성, 초안 작성, 수정,
  분량 축소와 리뷰어 대응을 수행하는 작업 흐름
- 출처, 적용 예외와 한계를 명시한 독자적인 분석 기록.
  수상 이력과 연구자 평판은 논문을 찾는 단서이며 보편적 작성 규칙의 근거는 아닙니다.

특정 연구 관심사에 한정하지 않고 HCI의 다양한 분야를 다룹니다.
단어 수 측정은 실제 측정 표본을 명시하며, 8,000단어 배분 예시는 보편적인
게재 규칙이 아닌 조정 가능한 편집 계획으로 제공합니다.

## 진행 과정 확인

[PLAN](docs/PLAN.md)은 단계별 계획과 현재 결정을 관리합니다.
[SAMPLING-PLAN](docs/SAMPLING-PLAN.md)은 표본 범위와 포함 기준을 정의합니다.
[REVIEW-LOG](docs/REVIEW-LOG.md)는 통합 전 검토 결과를 기록합니다.
[CORPUS](research/CORPUS.md)에서 검토한 논문 분석과 출처를 확인할 수 있습니다.
작은 분석 묶음마다 검토 후 별도로 커밋하고 푸시합니다.

저장소에는 독자적인 분석과 공개 서지 정보만 포함합니다.
원문 PDF, 전문 캐시, 비공개 Zotero 데이터와 모델 대화 기록은 로컬에 보관합니다.
최종 영문·한국어 문서, 설치 안내와 시각 디자인은 연구 종합과 작업 흐름 검증 후 완성합니다.
